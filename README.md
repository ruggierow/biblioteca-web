# Biblioteca Web — v.1.7.5

Interface web para gestão de catálogo de livros. Funciona como um arquivo HTML local, sem instalação.

## Download

Acesse a [página de releases](../../releases) e baixe o pacote para o seu sistema:

| Sistema | Arquivo |
|---|---|
| **Mac** | `Biblioteca-Web-Mac-v1.7.5.zip` |
| **Windows** | `Biblioteca-Web-Windows-v1.7.5.zip` |

## Uso rápido

**Mac:** extraia o ZIP, dê duplo clique em `Abrir Biblioteca.command`.  
**Windows:** extraia o ZIP, dê duplo clique em `Abrir Biblioteca.bat`.

> O Chrome é necessário para usar o recurso "Vincular arquivo" (sincronização automática com o biblioteca.txt).
> No Safari ou Edge, use **Importar** e **Exportar** para carregar e salvar os dados.
